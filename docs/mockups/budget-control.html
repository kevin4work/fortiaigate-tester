Budget-hit response


    

      402 — Payment Required. FortiAIGate tracks per-key spend against the configured hourly budget ($1.00/hour). When the hourly total reaches the limit, the gateway refuses further requests at admission — ≈0.2 s latency, zero tokens billed — with error.code = "budget_exceeded" and type = "payment_required_error". Enforcement lags one request boundary: the request that crosses the limit still succeeds; the next one is refused. A 402 carrying a different code, or any other status, is reported as-is and never relabelled as budget enforcement.
